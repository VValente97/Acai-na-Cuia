# Segurança

Este projeto é uma landing page estática executada localmente.

## Como reportar um problema

Não publique credenciais, tokens, dados pessoais ou arquivos de configuração em issues públicas. Para reportar um problema de segurança, abra uma comunicação privada com o responsável pelo repositório antes de divulgar o problema.

## Boas práticas do projeto

- Não adicionar arquivos `.env`, chaves, tokens ou senhas ao repositório.
- Manter dados de contato e o número do WhatsApp fora do código até serem confirmados.
- Revisar o repositório antes de qualquer push.
- Usar HTTPS e cabeçalhos de segurança quando o site for disponibilizado publicamente.
